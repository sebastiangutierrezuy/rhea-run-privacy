# Ñandú Salvaje

Repositorio utilizado para alojar la Política de Privacidad de **Ñandú Salvaje**, un videojuego móvil desarrollado en Uruguay.

## Privacy Policy

La política de privacidad está disponible mediante GitHub Pages.

Este sitio contiene información sobre el tratamiento de datos y los servicios de terceros utilizados por Ñandú Salvaje.

## Contacto

Para consultas relacionadas con privacidad o con el juego, podés contactar al desarrollador mediante el correo electrónico indicado en la Política de Privacidad.
